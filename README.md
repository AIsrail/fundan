# Fundan — funding opportunities for Kyrgyzstan and Central Asia

**Website:** https://fundan.cc · **English:** https://fundan.cc/en · **Telegram:** [@connect4_pro](https://t.me/connect4_pro) · **Bot:** [@c4faq_bot](https://t.me/c4faq_bot)

Fundan is a searchable database of **680+ grants, loans, investors, accelerators and fellowships** open to NGOs, businesses and startups in **Kyrgyzstan, Uzbekistan, Kazakhstan and Central Asia**. For every entry: funder, amount (or what is covered), deadline and intake status — open now, rolling, or closed and waiting for the next round. Local programmes come first, then regional, then international.

Made by [Connect4Pro](https://azatisrail.org) (Azat Israilov, Bishkek) from 15+ years of practical fundraising work.

## What you can use
| | |
|---|---|
| Open opportunities right now (JSON) | `GET https://fundan.cc/api/open-now` (`?audience=ngo\|business`, `?lang=en`) |
| Database size and last update | `GET https://fundan.cc/api/db-info` |
| Semantic search (free preview is limited) | `GET https://fundan.cc/api/search?q=…&lang=en` |
| OpenAPI description | https://fundan.cc/openapi.json |
| For AI systems | https://fundan.cc/llms.txt · https://fundan.cc/llms-full.txt |
| Directory of Kyrgyz business associations | https://fundan.cc/resources |

Programme conditions and deadlines change — always check the funder's official page (every entry links to it).

## Listing a programme
Run a programme open to organizations from Kyrgyzstan or Central Asia? Send the link to **connect4fund@gmail.com** — we review it and add it to the database.

# Fundan — финансирование для Кыргызстана и Центральной Азии

**Сайт:** https://fundan.cc

База из **680+ грантов, кредитов, инвесторов, акселераторов и стажировок** для НКО и бизнеса Кыргызстана и Центральной Азии: донор, сумма, дедлайн и статус приёма (открыто / постоянный приём / закрыто). Сначала местные программы, затем региональные и международные. Поиск понимает смысл запроса («теплица, своих денег мало» — найдёт агрокредиты и лизинг).

Бесплатно: список «Открыто сейчас», еженедельная рассылка дедлайнов в Telegram (@c4faq_bot, `/start weekly`), генератор идей проекта. Платно: подбор 5 вариантов (200 сом), доступ на месяц (300), 6 месяцев (1500 / 4500).
